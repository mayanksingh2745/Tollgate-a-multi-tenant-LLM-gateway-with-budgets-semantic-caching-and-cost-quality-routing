# Tollgate Benchmarks

This directory contains performance, latency, and throughput benchmark suites for Tollgate LLM Gateway.

## Benchmarking Focus Areas

1. **Proxy Latency Overhead**: Measuring P50, P95, P99 latency overhead introduced by budget checking, token counting, and semantic cache lookups.
2. **Concurrency & Throughput**: Evaluating requests per second (RPS) under high concurrent client load.
3. **Semantic Cache Hit Rates**: Benchmark vector similarity lookup performance in Redis / Qdrant.
4. **Streaming Overhead**: Measuring First Token Latency (TTFT) and token streaming chunk throughput.
